#M1L4-lvl3
##**Это бот-игра про покемонов**
![](https://i.ytimg.com/vi/IRj-fXHVqVY/maxresdefault.jpg)
###*Как это работает?*
**При запуске бота создай своего покемона!** *Не забудь прегласить друзей, ведь у бота пока нет открытого онлайн режима, пусть они тоже создадут покемона!*
Не забудь покормить своего покемона, чтобы он стал сильнее.
Отвечай на сообщения друзей командой "/attack", чтобы сражаться с ними.
***Возможно этот бот не будет больше совершенствоваться, потому что буду работать над новым ботом по покемонам (https://t.me/pokedota)-ссылка на него!***
